cr — Key/Speed Shift

Shift an audio file's key and speed with a preset, or run Auto-Fit to find a shift the song recogniser can't identify. Same tool as the bot's /cr command — you get the shifted MP3 plus a spectrogram.

Balanced: +2.0 semitones, 1.07x tempo. The recogniser check only happens in Auto-Fit.

Download MP3 Open spectrogram

Auto-Fit probes the file against AudD (the same recogniser as the Song Recognition tool) and takes up to a minute; presets run in a few seconds. Your file is processed by our server, the result sticks around for 15 minutes, and nothing is stored after that. This changes how a fingerprint matcher sees the file — it doesn't change who owns the song.
