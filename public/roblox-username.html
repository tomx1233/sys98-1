Roblox Username Check

Is that username still free? Roblox has no official "is this taken" API anymore, so this checks the same way the bot's /username command does: valid shape + nobody currently owns it.

Even a free-looking name can still be rejected at signup for other reasons (moderation, reserved words). Not affiliated with Roblox.
