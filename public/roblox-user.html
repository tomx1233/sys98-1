Roblox User Lookup

Type a username, a user ID or a profile link and see what is public on that account: names, created date, friends and followers, groups, Roblox badges and whether the inventory is visible.

Open profile on Roblox

Only what anybody can see on the public Roblox profile, looked up by our server for you and not stored. There is no online status, last-seen time or current game on purpose: that would turn this into a tool for tracking players, many of whom are kids. Not affiliated with Roblox.
