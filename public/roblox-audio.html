roblox-audio.sh
tool

Roblox Audio Info

Paste an audio ID or a Roblox link and see who made it, the artist, favorites, length and when it was uploaded. Below you can also drop an audio file to see its loudness, peak, bitrate and waveform.

Open on Roblox

Want to hear it and see its waveform? Roblox's page has its own Download button. Save the file there and drop it in the box below.

The info comes from Roblox's public web pages, looked up by our server for you. Nothing is stored. Roblox doesn't give out the audio file itself, so use the file box below for sound analysis. Not affiliated with Roblox.

file-analysis.sh

Analyze an audio file

Drop any audio file to see its format, loudness, peak, bitrate and a waveform. It never leaves your browser.

Loudness is measured as integrated LUFS (ITU-R BS.1770 with gating), peak is the highest sample in dBFS. Bitrate is the file average. Lossy files can peak above 0 dBFS after decoding.
