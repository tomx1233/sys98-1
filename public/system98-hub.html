README

Built by one person, not a team.

system98 came together over a few evenings because I was tired of the same small tasks: paste a link somewhere, wait for a download page, click away the third ad. Not here.

No tracking, no login, no data going anywhere. If a tool breaks or something's missing, just reach out.
